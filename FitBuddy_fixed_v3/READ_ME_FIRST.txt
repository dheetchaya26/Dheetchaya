FITBUDDY FIXED V3

1. Extract this ZIP.
2. Double-click run_fitbuddy_v3.bat.
3. If asked for a Gemini API key, paste it.
4. Open http://127.0.0.1:8000
5. Click Generate Plan.

This version uses the current Google GenAI SDK and prevents Gemini calls
from leaving the page waiting indefinitely. If Gemini is unavailable,
FitBuddy returns a demo/fallback plan instead of hanging.
